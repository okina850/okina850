- **金は日本株の下落に備える安全資産になるか** — コピュラと条件付きCVaRを用いて、円建てとドル建ての金を比較しました。円建ての金は、検証した6通りのモデル設定すべてで、日経225急落時の安全資産の基準を満たしませんでした。GPIF Finance Awards for Studentsに応募した自主研究です。
- **乱数生成法の研究** — 逆関数法による乱数生成に関して、関数近似を用いた数値実験をPythonで主導しました。日本応用数理学会2026年度年会でポスター発表しました。
